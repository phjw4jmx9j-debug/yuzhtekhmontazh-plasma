КАЛЬКУЛЯТОР ПЛАЗМЕННОЙ РЕЗКИ ЮЖТЕХМОНТАЖ — демонстрационная версия 0.1

Состав: index.html, app.js, sw.js, manifest.webmanifest, icon.svg.

Проверить на Windows: распакуйте архив и откройте index.html в браузере. Ручные расчёты, редактирование прайса, история, CSV и резервные копии работают локально. Для надёжной истории используйте один и тот же браузер и регулярно скачивайте резервные копии.

Чтобы установить на iPhone/Android как офлайн-PWA, нужно опубликовать эти файлы на HTTPS-хостинге. Затем один раз открыть сайт онлайн, дождаться загрузки, добавить сайт на главный экран (iPhone: Safari → Поделиться → На экран «Домой»). После этого проверить работу в авиарежиме. Сам архив не является iOS/Android-приложением и напрямую на iPhone не устанавливается.

Прайс из присланной фотографии. Первая цифра для листа 3 мм частично закрыта на снимке; в прототипе установлено 100 ₽/м — перед эксплуатацией проверьте. Для прочих толщин 4–40 мм введены указанные на фото цены. Программирование по прайсу «от 500 ₽» (значение редактируется в каждом заказе). Для учёта материала к длине и ширине добавляется по 30 мм, цена за квадратный метр вводится вручную. Скидки по объёму в прайсе без конкретных ставок, поэтому вводятся вручную. Прототип не вычисляет технологические нюансы плазменной резки и не читает DXF/DWG.

Для производственного использования нужно проверить алгоритмы на реальных заказах, актуальность прайса и обеспечить резервное копирование. При хранении конфиденциальных данных заказчиков потребуется отдельная оценка безопасности.
